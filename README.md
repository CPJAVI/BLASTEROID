# BLASTEROID

Juego de acción programado con HMTL/CSS/JavaScript
Para jugar ejecuta el comando: http-server -p 3008 o cualquier otro puerto que te guste, yo digo ese por poner un ejemplo
¡Navega al puerto que hayas elegido y que comience la aventura!
Usa las flechas del teclado para moverte
Barra espaciadora para disparar
Tienes 10 vidas
Recoge las gemas para ganar puntos
Cada nivel acabará cuando derrotes a todos los enemigos que aparecen
¡Buena suerte contra el jefe final!
